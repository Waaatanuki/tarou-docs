# 肉鸽情报

收集展示肉鸽中常用的数据信息。

![alt text](/assets/img/dungeon-img1.png)

## 节点信息

![alt text](/assets/img/dungeon-img2.png)

把地图上所有节点根据类型分类统计数量，悬浮显示图标含义

## 队伍信息

![alt text](/assets/img/dungeon-img3.png)

显示当前队伍血量信息，方便处理一些扣血事件，看血量是否达标

## 敌人信息

![alt text](/assets/img/dungeon-img4.png)

显示敌人血量，支持多目标，方便规划技能

## 导本信息

![alt text](/assets/img/dungeon-img5.png)

黄色表示标记的导本，会置顶显示，用于标记一些重要导本，通过点击切换标记状态。红框代表负面效果导本。筛选方式和游戏里一样。

## 地图信息

![alt text](/assets/img/dungeon-img6.png)

点击地图信息按钮打开地图弹窗，展示整个地图信息，底部特殊事件图标方便区分各种事件，提前规划线路。顶部和底部图标悬浮时都会在地图上高亮显示相应图标。
