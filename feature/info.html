用户信息 ​

用户信息用于登录太郎账号、查看会员状态、玩家 ID 和引继码。扩展与桌面端点击底部头像，再选择菜单顶部的账号项；移动端从菜单进入“用户信息”。太郎账号与游戏账号分别登录，登录太郎不会代替游戏登录。

登录与注册 ​

首次打开会显示登录表单，可以切换到注册，或通过“游客入口”查看本地资料。游客可使用本地展示功能；掉落上传与查询、配置查询与上传等云端功能需要登录太郎账号。

玩家 ID 从游戏自动获取，不能手动填写。未获取时，先在游戏中进入自己的个人资料页，再返回登录或注册。太郎账号需要与当前游戏玩家 ID 一致，切换游戏账号后需要登录对应的太郎账号。

注册时阅读并同意用户协议。“旧引继码”是选填项：以前使用过太郎且保留了旧码时，可以填写以关联原有身份；留空则由服务端生成。已有本地旧码不会自动填入注册表单，需要自行复制填写。

忘记密码时，点击“忘记密码”，填写用户名、原引继码和新密码，并确认已获取玩家 ID。

会员 ​

登录后显示会员到期时间，可以通过“兑换会员”输入兑换码。会员配置自动同步的使用方式见下文。

友招 ​

游戏中进入用户详细页面 https://game.granbluefantasy.jp/#profile 就可以获得友招信息。

扩展和桌面端会在用户信息下方直接展示友招卡片，点击“下载图片”保存，方便分享加好友。移动端不展示该区域。

引继码 ​

引继码用于关联太郎的云端数据，也用于重置密码。默认隐藏，可以点击查看或复制，请妥善保管。

旧版本升级

当前版本不再提供独立的“迁移引继码”按钮。首次注册时可填写旧码；已有太郎账号时请直接登录原账号。

配置上传同步 ​

有效会员登录后会自动拉取云端配置，之后配置变化也会自动上传，无需再点击“上传配置”或“同步配置”。非会员及游客不执行配置自动同步。

同步内容包括通知和音量、首页展示、掉落监控、神器规则、未持有角色等设置，以及抽卡记录和标记玩家等数据；不会同步整个客户端的数据。战斗记录、游戏登录状态、书签、桌面游戏代理和用户脚本不在同步范围内。

另一台设备登录同一账号并具备有效会员资格后会拉取配置；已经运行中的设备不会持续轮询其他设备的修改。网络失败时后台会重试。

登出 ​

扩展与桌面端从头像菜单登出；移动端在用户信息中操作。仅已登录时提供登出入口，游客即使保留旧引继码也不会显示。确认登出与登录失效一样，仅清除太郎登录凭据和账号资料、停止云端请求；引继码、游戏玩家资料、设置、书签和记录均保留，不会退出游戏网站账号，也不会删除服务端记录。
